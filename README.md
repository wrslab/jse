# 情報処理演習 (JSE)

大阪大学 基礎工学部 システム科学科「情報処理演習」（月曜3限）の授業ページ。

公開URL: <https://wrslab.github.io/jse/>

## 構成

| パス | 内容 |
| --- | --- |
| `index.html` | トップページ（日程・各コンテンツへの入口） |
| `assets/style.css` | 全ページ共通スタイル（ダークモード対応） |
| `text/` | 配布テキスト No.0〜No.8（PDF） |
| `examples/` | 例題プログラムと Tips |
| `kadai/` | 各回の課題 |

## 更新方法

1. 該当する HTML / PDF を編集する
2. `git add -A && git commit -m "..." && git push`
3. 数十秒で <https://wrslab.github.io/jse/> に反映される

## 公開しないもの

`.gitignore` で以下を除外している。**解除しないこと。**

- `students/`, `special/` — 受講生の学籍番号・氏名・成績に関する情報
- `*.ps`, `*.tex`, `*_ORG.pdf` — 配布は PDF のみ
