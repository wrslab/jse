C言語の関数

C言語の関数の仕様を詳しく知るためには，以下のコマンドを用いる． 

jman 3  関数名


使用例
$  jman 3 sin


********************************************************************************************

SIN(3)              Linux Programmer's Manual              SIN(3)

名前
       sin, sinf, sinl - 正弦 (サイン) 関数

書式
       #include 

       double sin(double x);
       float sinf(float x);
       long double sinl(long double x);

       -lm でリンクする。

説明
       sin() 関数は x の正弦 (サイン) の値を返す。ここで、x はラジアン単位で与えられる。

返り値
       sin() 関数は -1 と 1 の間の値を返す。

準拠
       SVID 3, POSIX, BSD 4.3, ISO 9899.  float 版と long double 版は C99 の要求仕様である。

関連項目
       acos(3), asin(3), atan(3), atan2(3), csin(3), cos(3), tan(3)

(END)
