自宅でC言語の自習

C言語は様々なシステムで使用できます． 本授業では GCC と呼ばれるCコンパイラが使用していますが， この他さまざまなメーカーがCコンパリラを販売しているし， 一部無料で使用できます． そこで，ここでは自宅でC言語を自習する方法について述べます．

(handy graphics はサイバーメディア独自に 開発したものなので，そのままでは使用できません)

  • Cコンパイラ

    • C言語を解釈して，計算機で実行できる形式に変換するソフト（コンパイラ） が必要です． ただし最近は，C言語だけでなく後継の C++ 言語を扱えるものになっています． C++ は，C言語を拡張した言語ですので，Ｃコンパイラとして使うことが出来ます．

    Microsoftからは Microsoft Visual Studio .NET 等が販売されていますが， 高価で，最近は高度化され初心者が簡単に使いづらくなってきています．

    無料の C コンパイラについてまとめて紹介されている，次のサイトを参考 にして下さい．

    • 日浦先生による borland C++ と MinGW のインストール の解説

  • 自宅でlinux

    • 本授業で使っているOSは linux と呼ばれるものです． このOS自体を自宅のパソコンにインストールするのも一つの案です． しかし，あまりコンピュータに慣れていないひとが行うのは若干危険 です． (他のOS 例えば windowsと同居させる様な場合，windows自体が動かなく なる場合もあります) なお，サイバーメディアセンターでは vineと呼ばれるパッケージが使用されています． 店頭販売もされていますが，フォント等の商用ソフトを除いたのもは 無料で使用できます (windows マシン以外にも Macintosh にもインストールできます)．

    その他，いくつかの linux システムが世の中にはあります． どれを使うかは，個人の好みです．

    • 日本のLinuxに関する情報
    • 各種ディストリビーシュンに関する情報
    • Free BSDと呼ばれるUNIXシステムに関する情報

    また，windows OS 上に linux OS をインストールすることもできます． つまり，windowsの1アプリケーションとして linux OSを動作させる方法で， エミュレータと呼ばれるものです．

    • Freeなlinux エミュレータ Cygwinの開発サイト
    • Windows上で動くLinux CoLinuxの開発サイト
