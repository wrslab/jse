XEmacs

Emacsは非常に高度なエディタ（文章を入力するソフトウエア）で，UNIXに慣れた 人には欠かせないものです．（一日の作業がEmacsに始まってEmacsに終わるという 人もいるくらい）．

情報活用基礎ではXEmacsを使用しますので，ここではその使い方について述べま す．

XEmacs はエディタと言うよりはアプリケーションの開発環境と言ったほうが近いで す．つまり XEmacs でプログラムを編集して XEmacs 上でコンパイルをして， XEmacs 上で実行させて，XEmacs 上で実行結果を見る．さらに，その結果を使って XEmacs でレポートを書く，というところまでできます．

さらにいうと，XEmacs があればメールや WWW なんかも利用可能です． 情報活用基礎では，XEmacs上でC言語のソースを書き，コンパイルし，実行させま す．

とりあえず，今日はそのはしりということで，立ち上げ方， 終了の仕方と簡単な ファイル編集の仕方をやります(なお，このホームページは，庄野先生（現奈良女 子大）のホームページを参考に作られました）．

  • 各部名称

    • それでは，各部分の名称を見ていきましょう． ウィンドウは大きく分けて4個の領域からなります．

    • メニューバー
      • 一番上にあるのがメニューバーで，ここで様々なコマンドが 実行できます(上図ではツールバーも一緒くたにくくってますが)．
    • 編集用バッファ領域．
      • ここでプログラムを編集したり，レポートを書いたりします． メインの領域なので1番大きな面積を占めています．
    • モードライン。
      • 現在の編集状態を示す領域です．XEmacs は色々なファイルを 編集するために，そのファイルのフォーマットに合わせた モードってのがあります． そのモードがどうなっているかを示す領域です．
    • ミニバッファ。(エコー領域)
      基本的に Emacs は何百というコマンドがあってメニューバーに 表示されているのは，ほんのわずかなので，その拾いきれない コマンドを打ったりするための領域です。

    そして全体を "フレーム" と呼びます。 Emacs ではフレームをいくつかに分割したりして １つのフレーム内に複数のウィンドウを持つことが可能です。

    このようにしてファイルは "バッファ" と呼ばれる Emacs の作業領域 に読み込まれます． ファイル名のお尻についているピリオド以降の文字を拡張子と呼びます． XEmacs はこれらの文字列を見て，編集モードを定めますので，変な 拡張子をつけておくと後々困ることになります． 拡張子は，

    拡張子名ファイルの種類
    .c C 言語のプログラムソースファイル
    .h C 言語のへッダファイル
    .txt テキストファイル
    .html HTML ファイル(ウェブのソース)

    などの種類があります。

  • 終了

    • XEmacs でファイルを編集して終了する場合には， やはりファイルメニューの一番下の行にある "Xemacs の終了 C-x C-c" を選択してください． キーバインドの "C-x C-c" は

    コントロールキーを押しながら x を押して，
    続いてコントロールキーを押しながら c を押す

    ということを意味します．この時，保存してないファイルがあると， XEmacs は(英語で) "保存されてないけど，保存するかい？" と聞いてきます．保存したい場合は慌てず "yes" を選択してください．

  • ファイルの保存

    • ファイルの編集が終了した場合には，ファイルの保存をしないと いけません(その編集したバッファを捨てたい場合は別ですが)． それには，ファイルメニューの "未保存バッファを保存 C-x s" を選んでください． (キーバインドはコントロール と x を同時押ししたあとに s を押す) ファイル名がすでに決定している場合には，現在表示されている バッファが保存されます． ファイル名が決定してない場合(ファイルを開くという操作をせずに *Scratch* と呼ばれるバッファで編集した場合)には， エコー領域にカーソルが移り

    File to save in : ~/

    のような聞かれ方をするので，そこでファイル名を打ち込んでください． (~/ はホームディレクトリを表します)

  • モードライン(実際の編集風景)について

    • モードラインを説明するには何か適当なファイルを編集するのが いいので，適当な C 言語のプログラムファイルを編集している画面を 眺めてみましょう．


    ウィンドウは小さくしてあります．

    このフレームでは "hoge.c" というファイルを編集しているところです． モードラインを見てみると

    Ja/EUC--**-XEmacs: hoge.c 7:50 (C Font)----L7--C1--All-------

    となってますが，これは

    • Ja/EUC : 日本語が扱えて，その場合日本語には EUC 漢字コードを 使う．
    • **: このバッファが既に何らかの編集されていることを意味します． 編集されてないときはこの部分は -- のままです．
    • hoge.c : 現在編集しているバッファに関連づけられたファイル名 セーブすると，この名前のファイルに保存される．
    • 7:50 : 現在時刻(出てない人もいるかも)
    • (C Font): 現在のモードを表します．
      • これは C 言語編集モードでキーワードが色違いになるように表示され ていることを示します．

      このほかのモードとしては

      • (Fundamental) : 基本モード(何にも特化してない)
      • (Text Fill): テキストファイル(.txt 拡張子) を編集してい る場合．
        • Fill は編集していてカーソル(Emacs の用語ではポ イント) が右端に達したら自動的に折り返すことを意味しま す．
      などがあげられます．

  • ファイルの編集

    • 通常の入力

      • それでは実際の編集を始めてみましょう．Emacs は (特殊なモードになっ てない限り) タイプした文字が，そのまま編集バッファに入力されます． "Hello Emacs !!" とタイプすれば，編集バッファにもそのよう な文字列があらわれるはずです．

    • カーソルの移動

      • カーソルの移動には，カーソルキーを使う場合もありますが，これらのキー はタイピングで言うところの "ホームポジション" から遠いので， タイプの上手な人は次のコマンドを覚えておくと便利です．

      コマンドキーバインドカーソルキー効用
      C-f→次の文字へ (forward-char)
      C-b←前の文字へ (backward-char)
      C-n↓次の行へ (next-line)
      C-p↑前の行へ (previous-line)
      C-a行の先頭へ (beggining-of-line)
      C-e行のおしりへ(end-of-line)
      M-<ファイルの先頭へ(beggining-of-file)
      M->ファイルのおしりへ(end-of-file)
      注)キーバインドの M-< と書いているやつは エスケープキーを押したのちに < キーを押す ということを意味します．

      • 文字を消去には，カーソルを動かして消したい文字の上まで持ってきます． そして

    • 行の消去(かっと)と貼付け(ペースト)について

      • もちろんマウスを使ってカットアンドペーストをすることも 可能ですが，キーボードになれてくるとマウスに手を伸ばすのが 億劫になってきます．こういう場合は以下のような方法を とります．

      行の消去には "C-k" (kill-line) を用います．ただしこのコマンドは， "現在のカーソル位置から行末までを消去する" コマンドなので，

        4. カーソルキーを移動させて，貼付けたい位置にまで， カーソルを持っていきます．
      4. 持っていったら "C-y" (yank) コマンドを実行すると 消した行の内容が，ペーストされます．

  • 日本語について

    • 日本人が日本語を使いたいと思うのは，当然の行為です． 当然のことながらサイバーメディアセンターの XEmacs も 日本語の入力と表示が可能です．

    いろんな Web のページを見ると "たまご" (たくさん，またせて，ごめんなさい，の略らしい…)を つかったものが多いですが，いろんな相性問題とか日本語入力時の キーバインドの問題があって，サイバーメディアセンターの XEmacs では，XWnmo という日本語入力システムを使ってます．

    これの問題点は，

    カーソル位置(On-the-Spot)で日本語変換ができない

    ということがあげられます．つまり日本語変換を実行しているときは， ウィンドウのいっちゃんしたの行に XWnmo のウィンドウが出てるので そこで変換された日本語が XEmacs に送られるという方式をとってます． On-the-Spot 変換に慣れた人にとっては，とっても気持悪いですが そういうものだと思ってあきらめてください．

  • ありがちな罠

    • フレームが二つに割れてしまったら

      • Emacs は，複数のファイルを同時編集することが可能です．このとき A と いうファイル をみながら B を編集するなんてことができますが， この時フレームを二つ(以上)に分けて編集することが可能です． この時画面は，

      のようになります．図では C 言語のプログラムを編集しながら， C 言語で使う printf() という関数のマニュアルを見ている． ていうつかいかたができたりします．

      意図してフレームを二つのウィンドウに分けるうちはいいんですが， 意図せず別れてしまうときもあります． そんなときは慌てずに， ファイルメニューの中にある "分解解除 C-x 1" を選びます．

      ただし，この時点で編集カーソルが保持しておきたいウィンドウの 中にないと編集したくないバッファが表示されてしまいます． そうなってしまったときは慌てずに， メニューの "バッファ" の中から自分の編集したいバッファを選んでください．

    • わけがわからなくなったら(妙だと思ったら)

      • Emacs で編集していて，間違って何か変なキーを押してしまうとキーが 聞かなくなることがあります．そういったときは迷わず C-g (コントロールキーを押しながら g を押す) を連打 しましょう．C-g の効用は "Keyboard quit" です．つまり 間違って変なキーを押してしまった時に，そのコマンドを キャンセルする際に使います．

      これでもなおらない場合，それはたいてい日本語回りです． C-\ か，Alt-[全角/半角] を押して日本語モードをオンオフして みてください． サイバーメディアセンターでは諸々の理由により XEmacs で日本語 編集をする場合 Xwnmo というアプリケーションを使用することを 推奨してます．ところがこの XWnmo と XEmacs との相性が悪いらしく カーソル位置(on-the-spot)で日本語変換ができないらしいです． そこで XWnmo というディスプレイ上のいっちゃん下の部分に出てくる ウィンドウでかな漢字変換を行います．これがオンになってると キーボードの入力はすべてそこに流れていってしまいます． 特にファイル名を入力しているときにかな漢字変換をオンにすると ひどいめに合います．
